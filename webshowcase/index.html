This isn't just a toy demo. The starred example below is the exact test that runs against a real, independently-built production app (Supply Chain Intelligence Platform) — not this project's own sandbox. Running it there caught a genuine bug (a race between a URL assertion and a Single Page App's async navigation), now fixed in every generated adapter. See docs/troubleshooting.md for the full writeup.
